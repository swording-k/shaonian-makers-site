# 少年创想家官网 · 开发交接

先读 [项目规则](../AGENTS.md) 和 [设计基线](DESIGN.md)。最近改动、分支和上线证据见 [交接日志](HANDOFF.md)。

1. 在目标分支修改 `site/public/` 的源码。新增或替换组件时查 [动效台账](MOTION-LIBS.md)。
2. 选择构建目标。[README](../README.md) 列出静态、离线和 Worker 的命令，以及本地预览方式。
3. 比对正常和减少动态模式，检查桌面、平板和手机宽度。验证作品换卡、咨询弹窗、课程选择、活动筛选、详情与返回。
4. 涉及首屏加载时检查首帧、慢网和资源请求，确认学习区重型组件到视口附近才加载。涉及章节衔接时检查第二屏边界和短屏行为。
5. 发布前确认目标仓库分支、生成文件、域名和保留的配置。以公网实际打开的版本判断发布是否生效。手机与微信内未实测的项目记录在交接里。

团队活动表联调时，分别验证运营新增、改期、关闭报名、补公众号回顾、移除记录。飞书访问和凭据通过部署环境配置，见 [飞书接入](FEISHU.md)。
