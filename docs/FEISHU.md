# 少年创想家 · 活动表与官网同步

更新：2026-11-27（分支 `feat/feishu-events`，未上线）

运营在飞书多维表里填一条活动，半小时内官网「活动与作品」自动出现一张卡片，不需要改代码，也不需要重新发版。

## 谁在哪里操作

- **运营**：打开飞书表单填活动，或在多维表里直接加一行。发布状态改成「已发布」即上线；改回「草稿」即下线。
- **家长**：官网免登录看卡片，点开跳到公众号原文 / 视频号 / 报名链接。
- **网站**：只读，没有任何编辑入口，也没有后台服务。

## 字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 活动标题 | 文本 | 是 | 卡片大标题，建议 20 字内，带日期更好认 |
| 活动简介 | 文本 | 是 | 卡片副标题，取前 160 字 |
| 活动形式 | 单选 | 是 | 线下营 / 线上社群 / 线上课程 |
| 开始时间 | 日期时间 | 是 | 北京时间 |
| 结束时间 | 日期时间 | 是 | 必须晚于开始时间；填实际结束时刻 |
| 活动地点 | 文本 | 否 | 线下填场馆，线上可留空 |
| 活动封面 | 附件 | 是 | 竖图或横图都行，卡片裁成 16:9 显示；不填也能上线，只是卡片变纯文字 |
| 公众号原文 | 超链接 | 否 | 填公众号文章地址，卡片点开就跳这里 |
| 视频号链接 | 超链接 | 否 | 回顾类活动填视频号，优先用公众号原文 |
| 报名状态 | 单选 | 否 | 开放 / 满员 / 关闭，只有「开放」才渲染报名入口 |
| 报名链接 | 超链接 | 否 | 报名或付费页，https |
| 活动状态 | 单选 | 否 | 正常 / 延期 / 取消；取消进往期并标「已取消」，延期标「时间待定」 |
| 发布状态 | 单选 | 是 | 草稿不展示，已发布才同步到官网 |

卡片的跳转优先级：公众号原文 → 视频号 → 报名链接。三个都没填的卡片不可点，也不显示箭头。

## 数据怎么流到官网

```
运营填表（飞书）
      ↓ 每 30 分钟 / 手动点一次
GitHub Actions（sync-feishu-events.yml）
      ↓ node site/tools/sync-feishu-events.mjs
data/events.json + assets/events/*.jpg（提交回 main）
      ↓ Pages 构建
官网 site.js 读 ./data/events.json 渲染卡片
```

- 脚本只取「已发布」，按开始时间升序；结束时间在过去或状态为取消的进「往期回顾」。
- 第一期的 11 月 22 日回顾是内置真实素材，固定留在往期，与活动表无关。
- 封面附件由脚本下载成 `assets/events/<record_id>-cover.jpg`，不依赖飞书的临时链接。
- 生成数据是覆盖式：表里删掉或改回草稿，下次同步卡片就消失。不用手改 `events.json`。

## 本机预览与验收

本机已登录的飞书账号可以直接读表，不需要应用凭据：

```bash
node site/tools/sync-feishu-events.mjs \
  --source=lark-cli \
  --base=LIe4bCQtqagOXRsse4ace1UQnCY \
  --table=tblVLvZqoOwoS6LT
npm run build:static
python3 -m http.server 8765 --bind 127.0.0.1 -d dist/static
```

浏览器打开 `http://127.0.0.1:8765/index.html#events`。改一条记录、再跑一次脚本即可看到变化。

CI 模式用同一份脚本、同一个映射逻辑，只是数据源换成应用凭据：

```bash
FEISHU_APP_ID=... FEISHU_APP_SECRET=... \
node site/tools/sync-feishu-events.mjs --base=$FEISHU_BASE_TOKEN --table=$FEISHU_TABLE_ID --out=.
```

## 验收清单（接上凭据后按这个走）

1. 新增一条，发布状态「草稿」，跑一次同步：官网没有变化。
2. 改成「已发布」，再跑：近期活动出现卡片，封面正常，点开跳到公众号原文。
3. 改开始时间到过去：卡片自动落到「往期回顾」。
4. 报名状态改「关闭」：报名入口消失；改「开放」并填链接：入口回来。
5. 活动状态改「取消」：卡片标「已取消」，不进近期。
6. 删掉记录：卡片消失。
7. 手机与微信内置浏览器各走一遍跳转。

## 边界

- 公众号正文不自动抓。个人号/服务号接口权限卡得死，运营粘原文链接、官网只做跳转，是最省事也最不容易坏的做法。
- 只支持单条活动的增删改；一期活动要从招募变回顾，直接改同一行的链接和时间即可，卡片不会生成新网址。
- 活动详情独立页（`/events/<id>/`）尚未做，当前卡片是外链直跳。要做详情页时再补 `event.html` 的数据接入。
