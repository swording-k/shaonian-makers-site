# 少年创想家官网 · 简约科技风重设计总方案

> 历史提案。以下保留早期探索，当前页面以 [设计基线](DESIGN.md) 为准。

## 一、唯一核心概念

**「从点子到作品」——整站本身就是一次构建过程的演示。**

页面按用户的认知旅程组织：提出点子（首屏）→ 理念（宣言）→ 怎么学（课程）→ 学完能怎样（能力三联）→ 什么时候参加（活动）→ 怎么找到我们（联系）。每个章节的动效形式服务于该章节的含义，不是装饰。

## 二、页面流转逻辑（用户最关心的）

1. **章节色带节奏**：黑（首屏）→ 白（理念+课程）→ 黑（活动）→ 白（联系）→ 黑（页脚幕布）。硬切色块分章，不用渐变过渡。
2. **导航栏墨色自适应**：sticky 顶栏随当前滚动到的章节自动切换深浅底色（已实现，保留）。
3. **滚动进度条**：顶栏底部 2px 钴蓝进度条（已实现，保留）。
4. **锚点跳转**：导航点击平滑滚动到对应章节；当前章节的导航项高亮。
5. **幕布页脚**：滚到底部，页脚从主内容下方揭开（已实现，保留）。
6. 每章只有一个视觉焦点，深浅交替保证节奏感，避免"全是一个样"的滚动体验。

## 三、动效预算表（全局只允许这些，一个萝卜一个坑）

| # | 位置 | 动效 | 技术 | 为什么 |
| --- | --- | --- | --- | --- |
| 1 | 首屏 | 入场编排：标题两行升起 + 照片快门打开 + 正文按钮淡入 | CSS keyframes + clip-path | 页面第一印象，1.2 秒内完成，首帧可读 |
| 2 | 理念宣言 | 「把想法 ● 做成真的」分屏随滚动左右推开 | GSAP ScrollTrigger scrub | 页面级空间感，文字围绕焦点移动 |
| 3 | 课程区 | 产品切换时的光学扫光（钴蓝色带横扫） | GSAP timeline | 唯一的组件级转场，切换有"翻页"感 |
| 4 | 能力卡 A「提出真问题」 | 文字逐行墨色填充（灰→黑随滚动） | ScrollTrigger scrub | 阅读节奏，非粒子 |
| 5 | 能力卡 B「指挥智能体」 | SVG 流程图线条逐段绘制 | stroke-dashoffset | "指挥"的可视化，非粒子 |
| 6 | 能力卡 C「做出真作品」 | **粒子聚合成对号 ✓（全站唯一的粒子效果，宝剑点名保留的那个）** | Canvas | 高潮时刻，放在"做出来"的位置，含义完全对应 |
| 系统层 | 全站 | 顶栏墨色自适应 + 进度条 + 按钮 hover/press 微反馈 | CSS | 交互手感，不抢戏 |

**明确禁止**：粒子效果出现在 6 号位之外的任何地方；跑马灯；文字 scramble 打字机；磁吸按钮；空态粒子点阵；每节一模一样的 fade-up。

## 五、动效技术底座

- GSAP 3.15 + ScrollTrigger（本地已有，无 CDN 依赖）
- 全部动效遵守 prefers-reduced-motion：降级为静态完成态
- 只动 transform / opacity / clip-path，帧率友好
- 每个 Canvas 动效用 IntersectionObserver 控制显隐，离屏即停
