# 少年创想家 · 活动录入与飞书接入

## 谁在哪里操作

运营用已有的飞书企业账号进入团队活动表，表格权限决定谁可以录入和修改。家长在官网免登录查看活动、读文章、听语音、打开报名链接。官网没有编辑入口，读表应用只有读取权限。

打开项目根目录的 `site-demo.html` 可以检查公开页面。当前本地预览及 GitHub Pages 均展示活动空态。飞书尚未完成真实接入，后端代码需要单独部署与授权。

## 正式录入表

使用公司名下的活动多维表，只将这张表授权给网站应用。运营直接在活动表维护内容，家长报名名单留在现有报名渠道。每期使用同一行。正文或语音有变化时改该行，发布状态切到「已发布」才展示。

| 字段 | 类型 | 内容 |
| --- | --- | --- |
| 活动标题 | 文本 | 必填 |
| 开始时间 | 日期时间 | 北京时间，正常排期必填 |
| 结束时间 | 日期时间 | 北京时间，正常排期下必须晚于开始时间。填实际结束时刻 |
| 发布状态 | 单选 | 草稿、已发布 |
| 活动状态 | 单选 | 正常、延期、取消 |
| 文章正文 | 文本 | 官网展示正文，保留换行 |
| 公众号原文 | 链接 | 填微信公众号文章链接 |
| 报名状态 | 单选 | 开放、关闭、满员 |
| 报名链接 | 链接 | 正式报名或付费页面 |
| 语音链接 | 链接 | 可播放的 HTTPS 音频文件链接。先将音频上传到公司允许对外播放的存储，再粘贴音频直链。飞书附件预览页不作为音频直链 |

## 管理员接入

1. 确认现有的**多维表格链接**，或在公司空间创建活动表。记录表的 Base Token 与 Table ID。
可从 [活动表字段模板](FEISHU_EVENTS.csv) 导入字段，将日期、状态和链接字段按上表设为对应类型。示例行保持「草稿」。

2. 在飞书开放平台创建或复用自建应用，配置查询多维表格记录的权限，向该应用开放指定活动表的读取权限，完成组织内部发布与授权。
3. 将 App ID、App Secret、Base Token、Table ID 通过网站的安全环境变量配置，变量名见项目的 `.env.example`。App Secret 仅在服务端配置，勿贴到聊天、表格或代码。
4. 在表格中发布一条活动，重新打开官网进行检查。服务端最多缓存约 1 分钟。若读取失败，有缓存时保留原文与回顾，并暂时隐藏旧报名入口。网站上线前与运营核对音频、原文和报名链接。

站点包含 Worker 的只读接口，后台录入由飞书处理。只有取得并配置团队应用的真实授权后，才会显示飞书来源的内容。无需在用户浏览器中暴露飞书凭据。
