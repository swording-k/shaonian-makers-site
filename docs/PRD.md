# 少年创想家官网 · 产品需求

> 当前官网已上线，运营自动更新仍待联调。正式域名、构建方式与预览见 [README](../README.md)。

## 目标与用户

家长通过微信推文、朋友分享或搜索打开官网，能够看懂课程与社群，确认近期活动时间，找到报名或联系入口。孩子能看到动手做项目的样子。团队运营人员用现有公众号首发，通过自动导入或内容表单维护官网活动，无需改代码和手动发版。

## 运营和状态

- 运营先发公众号，再让官网出现活动。P0 支持在飞书多维表格或团队选定的内容源填一条记录。标题、时间、地点、报名链接和原文链接只录一次。已发布记录在约定时间内刷新到官网。
- 官网把公众号全文交给原文入口。P1 验证账号能否自动读取正常发出的新推文；验证成功后导入并关联活动。若普通品牌推文也会进入接口，用内容类别或经运营确认关联，避免整号文章默认上官网。
- 报名与活动进程独立。未开始的活动可能暂未开放、已满、已截止或无报名链接。进行中、结束、延期和取消时停用报名入口；延期补齐新日期后可重新开放。
- 回顾没有发出时保留活动页和预告原文，可显示「回顾待更新」。补文章、添加作品或改活动时间不会产生新活动网址。

## 可交付判定

- 本地开发：可用标明「示例」的内容完成所有页面和状态。视觉原型的排版和交互是第一版视觉基线。
- 运营联调：运营本人完成新增、改期或关闭报名、补回顾三件事，并确认无需接触代码。活动详情在微信内能打开公众号原文及报名地址。
- 生产上线：已替换示例素材，填妥实际团队联系方式，正式活动和报名信息已核对，完成手机与微信内验证。公众号自动读取单独验收，P0可先使用表单。
- 首版范围止于公开展示和外部报名。知识库及其他社群可在有真实链接后放页脚。会员卡、站内支付、学员登录和站内表单收集报名资料留后续评估。
