# 少年创想家 · 当前视觉与交互

以下以 `design/fast-first-paint` 的可预览页面为准。公司站与本地分支可能对应不同发布版本，见 [交接日志](HANDOFF.md)。

- **视觉。** 浅灰白底、墨色文字、品牌四色波浪标，钴蓝用于开场和章节衔接。中文大标题用宋体，正文用清晰黑体，英文短句用自托管 Instrument Serif Italic。用真实学员作品作为画面主角。
- **开场。** 从蓝色棱纹和品牌标志进入，支持跳过和 Esc。首屏就绪后交叠淡出。减少动态、浏览器返回和直达子章节时直接显示对应内容。
- **首页。** 左侧保留「把点子，做出来。」和课程入口，右侧作品堆包含三张真实作品和一张「敬请期待」。鲨鱼海洋铺底，输入框发送后弹出企微二维码。网站引导用户添加后与老师沟通。
- **理念与课程。** 滚动时浅蓝曲线覆盖首屏，理念文字接续出现。课程索引展示线下一日营、少年创想家·青少年AI实战成长营、AI 高效育儿俱乐部·线上社群、长期线上营。社群项打开企微二维码，待发布的排期和课程内容使用明确状态。
- **三个学习场景。** 「提出真问题」使用 Agent 输入框演示，「指挥智能体」用思考强度滑块，「做出真作品」展示第一期学员卡丁车截图。前两栏为页面内示例。
- **活动与联系。** 活动可按近期和往期筛选，第一期 11 月 22 日青少年 AI 线下一日营直接链接视频号。联系区提供企微和老师视频号，二维码可以点开。
